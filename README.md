# Local AI Web UI

Eine leichtgewichtige Gradio-Weboberfläche für lokal laufende Sprachmodelle über eine OpenAI-kompatible API.

## Voraussetzungen
- Python 3.10+
- Ein laufender lokaler Modell-Server (z. B. Ollama, LM Studio oder AMD Lemonade)

## Installation & Start
```bash
pip install -r requirements.txt
python app.py
